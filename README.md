# SkillSwap – Skill Exchange and Micro Learning App

## About the Project

SkillSwap is a peer-to-peer learning platform that allows students to teach and learn skills from each other. Users can add the skills they can teach, the skills they want to learn, their skill level, and availability.

The system helps users find suitable skill-learning partners and supports skill-swap requests and learning sessions.

## Features

- User registration and login
- Secure user authentication
- User profiles
- Add skills to teach and learn
- Skill level management
- Availability management
- Skill matching
- Skill-swap requests
- Learning session management
- Real-time communication support
